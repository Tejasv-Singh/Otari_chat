    Otari usage, selected run (recorded live)

    Recorded runs, replayed offline. Every model call in these runs went live through a self-hosted Otari gateway: one virtual key per cohort, per-run token budgets, a routing policy per model family, and a misinformation guardrail on every interpretation. The page replays those answers call for call, so no gateway is needed to view it.
